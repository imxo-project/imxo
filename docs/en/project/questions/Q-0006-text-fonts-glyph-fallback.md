**Status:** OPEN  
**Area:** Text  
**Source:** PREP-00

## Question

How should IMXO represent text, fonts, and glyph fallback?

## Context

IMXO must allow text to be associated with an image and its regions, but the exact normative text model has not yet been defined.

## Scope

- whether and when fonts may or must be embedded;
- licensing constraints;
- whether glyph raster fallback is required;
- fallback rules;
- relationship between displayed and copyable text;
- behavior when the original font is unavailable;
- complex writing systems.
