# RSCH-0010. Угрозы ИИ-потребления и отмывание семантики

**Status:** DRAFT  
**Area:** Security / AI consumption  
**Related questions:** Q-0007, Q-0008, Q-0012  
**Related requirements:** none  
**Related use cases:** USE-0003  
**Supersedes:** none  
**Created:** 2026-10-18

## 1. Исследовательский вопрос

Какие угрозы возникают при передаче растра и структурированных утверждений ИИ-системе, включая внедрение инструкций, потерю контекста и повторное представление производного вывода как независимого факта?

## 2. Границы исследования

Входят prompt injection через видимые и структурные данные, граница data/instructions, адаптеры, provenance loss, semantic laundering и полномочия исполнительной системы. Не входят протокол автономных действий, промпты IMXO и встроенная активная логика.

### Критерии завершения

Составлена модель угроз с активами, границами доверия и злоупотреблениями; меры разделены между форматом, адаптером, моделью и исполнительной системой; активное поведение не перенесено в IMXO.

## 3. Источники

- OWASP и другие авторитетные threat-model документы для LLM/agent systems;
- первичная документация платформ о разделении данных, инструментов и инструкций;
- рецензируемые исследования indirect prompt injection и provenance loss.

Для каждого использованного источника требуется зафиксировать организацию или автора, точную редакцию либо версию, дату, ссылку и релевантные разделы. Проверяются актуальность, первичность и применимость источника; рекламные заявления не принимаются как доказательство.
