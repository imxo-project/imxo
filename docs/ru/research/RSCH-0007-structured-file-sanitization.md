# RSCH-0007. Санитизация структурированных файлов

**Status:** DRAFT  
**Area:** Privacy / Sanitization  
**Related questions:** Q-0002, Q-0012, Q-0014  
**Related requirements:** none  
**Related use cases:** USE-0002  
**Supersedes:** none  
**Created:** 2026-10-18

## 1. Исследовательский вопрос

Какие проверенные модели и инструменты удаляют выбранные значения из видимых, скрытых, производных и исторических представлений структурированного файла и как проверяют результат?

## 2. Границы исследования

Входят PDF/Office и другие сложные документы, обезличивание структурированных данных, история, производные значения, экспорт и проверка. Физическое стирание носителя рассматривается только как граница. Стеганография внутри медиаданных вынесена в RSCH-0008.

### Критерии завершения

Сравнены минимум три класса структурированных данных; отделены обнаружение, преобразование и проверка; сформулированы тестируемые последствия без требования конкретной реализации.

## 3. Источники

- официальная документация форматов и средств redaction/sanitization;
- нормативные руководства по media sanitization для разграничения задач;
- документация инструментов anonymization/masking и проверки преобразований;
- опубликованные разборы известных отказов санитизации.

Для каждого использованного источника требуется зафиксировать организацию или автора, точную редакцию либо версию, дату, ссылку и релевантные разделы. Проверяются актуальность, первичность и применимость источника; рекламные заявления не принимаются как доказательство.

## 6. Последствия для IMXO

Оценить общие свойства операции, failure reporting и conformance fixtures для Q-0014, не назначая алгоритм или API.

До завершения исследования этот раздел перечисляет только вопросы для оценки и не является требованием, проектным решением или рекомендацией.

Дополнительно провести границу между обычным редактированием и санитизацией на примерах перемещения, копирования, частичного вырезания, объединения, обрезки и перекрытия. Проверить, какие состояния и остаточные данные допустимы для обычного редактирования, но недопустимы для заявленного санитизированного результата.
