# Сценарии применения IMXO

Этот каталог содержит информативные карточки `USE`, описывающие сценарии применения IMXO.

`USE` отвечает на вопрос:

> кто или какая система, в каком контексте, какую проблему решает и какой результат требуется?

`USE` не является:

- нормативным требованием;
- архитектурным решением;
- исследовательским доказательством;
- обещанием включить функцию в конкретную версию стандарта.

Процесс и lifecycle `USE` определены в [`PREP-08`](../project/PREP-08-use-case-research-planning-process-amendment.md). Новые карточки создаются по [`USE-template.md`](../templates/USE-template.md).

## Статусы

Карточка может иметь статус:

- `DRAFT`
- `REVIEW`
- `COMPLETE`
- `WITHDRAWN`
- `SUPERSEDED`

## Disposition

Независимо от зрелости документа используется:

- `CANDIDATE`
- `TARGET`
- `NON-TARGET`
- `DEFERRED`

`COMPLETE` означает зрелость описания.

`TARGET` означает, что сценарий рассматривается как целевой для развития IMXO.

Ни одно из этих состояний не создаёт автоматически нормативных требований.

## Языковой процесс

Новые карточки разрабатываются на русском языке.

До `COMPLETE` английская версия необязательна, но может быть создана раньше для внешнего review или сотрудничества.

При переходе карточки в `COMPLETE` английская зеркальная версия становится обязательной.

Если обе версии существуют, они должны сохранять одинаковые ID, смысл, Status, Disposition и связи с другими артефактами.
