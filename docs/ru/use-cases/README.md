# Сценарии применения IMXO

Этот каталог содержит информативные карточки `USE`, описывающие сценарии применения IMXO.

`USE` отвечает на вопрос:

> кто или какая система, в каком контексте, какую проблему решает и какой результат требуется?

`USE` не является:

- нормативным требованием;
- архитектурным решением;
- исследовательским доказательством;
- обещанием включить функцию в конкретную версию стандарта.

`Status` показывает зрелость документа, а `Disposition` — место сценария в проекте; эти характеристики независимы. Процесс и lifecycle `USE` определены в [`PREP-08`](../project/PREP-08-use-case-research-planning-process-amendment.md). Новые карточки создаются по [`USE-template.md`](../templates/USE-template.md).

## Статусы

Карточка может иметь статус:

- `DRAFT`
- `REVIEW`
- `COMPLETE`
- `WITHDRAWN`
- `SUPERSEDED`

## Disposition

Независимо от зрелости документа используется:

- `CANDIDATE`
- `TARGET`
- `NON-TARGET`
- `DEFERRED`

`COMPLETE` означает зрелость описания.

`TARGET` означает, что сценарий рассматривается как целевой для развития IMXO.

Ни одно из этих состояний не создаёт автоматически нормативных требований.

## Планируемые сценарии

Записи ниже являются только рабочим roadmap. Эти карточки ещё не созданы, не имеют официальных `Status` и `Disposition` по PREP-08 и станут реальными артефактами `USE` только после создания соответствующих файлов. Рабочие номера отражают текущий согласованный порядок обсуждения.

| Рабочий номер | Рабочее название | Зачем нужен |
|---|---|---|
| `USE-0002` | Безопасное скрытие и удаление данных в структурированном изображении | Исследовать каскадное удаление или обновление текста, семантики, аннотаций, метаданных и альтернативных представлений во всей экосистеме редактирования IMXO, включая будущие повторно используемые механизмы официальных библиотек без запрета независимых реализаций. |
| `USE-0003` | Снимок экрана как вход для ИИ-агента | Рассмотреть автоматическое потребление структурированного снимка, при котором расхождения представлений могут влиять на действия, а provenance, trust и конфликты данных становятся центральными. |
| `USE-0004` | Изображение с разметкой компьютерного зрения | Описать созданные человеком или машиной boxes, polygons, masks, labels и другие CV-аннотации, их происхождение, связь с распространёнными экосистемами и сохранение корректности после редактирования изображения. |
| `USE-0005` | Долговременное научное, музейное или архивное изображение | Рассмотреть длительное хранение, preservation, migration, offline/self-contained use, provenance и verification horizon без лишней зависимости от внешних сервисов. |
| `USE-0006` | Изображение с машинно созданной семантической разметкой | Рассмотреть растр вместе с объектами, областями и описаниями от камеры, средства захвата или последующего анализатора, происхождение и доверие к машинным утверждениям и их повторное использование разными потребителями. |
| `USE-0007` | Доступное структурированное изображение для пользователя программ специальных возможностей | Рассмотреть не ограниченный alt text доступ к значимому визуальному и семантическому содержимому для пользователей, которые не могут полностью воспринимать растр: к тексту, описаниям, областям, отношениям и существующим CV/camera-аннотациям с учётом их происхождения и различия между возможностями формата и accessibility API программы просмотра или платформы. |

## Языковой процесс

Новые карточки разрабатываются на русском языке.

До `COMPLETE` английская версия необязательна, но может быть создана раньше для внешнего review или сотрудничества.

При переходе карточки в `COMPLETE` английская зеркальная версия становится обязательной.

Если обе версии существуют, они должны сохранять одинаковые ID, смысл, Status, Disposition и связи с другими артефактами.
