# Q-0001. Контейнерная архитектура IMXO

**Status:** OPEN  
**Area:** Container  
**Source:** PREP-00  
**Created:** 2026-09-19

## Вопрос

Должен ли IMXO использовать полностью собственный контейнер, профиль или надстройку над существующим контейнером либо гибридный подход?

## Контекст

Контейнерная стратегия определит основу физической модели IMXO. PREP-00 не выбирает вариант: решение должно быть принято только после исследования существующих контейнерных архитектур и альтернатив.

## Область вопроса

- полностью собственный контейнер IMXO;
- профиль или надстройка над существующим контейнером;
- гибридный подход;
- последствия вариантов для требований и последующего проектирования;
- представление зависимых и производных данных при санитизации;
- обработка непрозрачных и неизвестных вложенных данных;
- возможность безопасно сформировать итоговый файл без удалённого содержимого.

## Связанные исследования

Пока не назначены.

## Связанные требования

Пока отсутствуют.

Не принято.
