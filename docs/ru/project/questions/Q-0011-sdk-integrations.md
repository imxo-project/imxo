# Q-0011. SDK и интеграции

**Status:** OPEN  
**Area:** Implementation  
**Source:** PREP-00  
**Created:** 2026-09-19

## Вопрос

Какой должна быть будущая модель SDK, API и интеграций IMXO после стабилизации базовой архитектуры?

## Контекст

PREP-00 не принимает окончательных решений по SDK и интеграциям. Эти вопросы рассматриваются позднее, когда основные модели станут достаточно стабильными. Планируемый USE-0004 требует учесть редакторы с полной и частичной поддержкой структуры, не проектируя API заранее.

## Область вопроса

- SDK и API;
- Windows, Linux, macOS и Android;
- браузеры;
- Photoshop, GIMP и Krita;
- системные просмотрщики изображений;
- viewer/editor integration;
- инструменты захвата экрана;
- высокоуровневые безопасные операции изменения и удаления без преждевременного назначения конкретных API;
- высокоуровневые операции обычного редактирования для перемещения, копирования, разделения, объединения, обрезки и перекрытия без определения конкретных вызовов SDK;
- информирование о непроверенной актуальности связанных утверждений после изменения;
- частичная поддержка структуры редакторами без молчаливого объявления результата полностью согласованным;
- безопасная передача состояния и известных ограничений после изменений;
- обработка связанных изменений, удалений и проверка итогового состояния;
- возможность корректной реализации без ручного обхода внутренних структур контейнера каждым приложением;
- поведение при частично поддерживаемых расширениях и формирование состояния, пригодного для экспорта.
