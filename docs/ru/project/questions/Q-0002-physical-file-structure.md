# Q-0002. Физическая структура файла

**Status:** OPEN  
**Area:** Container  
**Source:** PREP-00  
**Created:** 2026-09-19

## Вопрос

Как должна быть устроена физическая структура файла IMXO?

## Контекст

PREP-00 намеренно не определяет бинарную структуру до исследования контейнерных вариантов и уточнения требований.

## Область вопроса

- сигнатура файла, endian и общий заголовок;
- размеры и структура заголовков блоков или чанков;
- `type`, размеры, `uint64`, `object_id` и flags;
- CRC заголовка и содержимого, криптографические хэши;
- вложенность, footer, основной и резервный индексы;
- recovery sync marker, padding и alignment;
- обход повреждённых данных;
- сохранение неизвестных блоков;
- удаление данных из устаревших блоков, остаточных структур, индексов, свободных областей и padding, если выбранная физическая модель содержит такие элементы;
- безопасное формирование конечного файла и поведение при прерывании операции;
- конфликт между сохранением неизвестных блоков и гарантией удаления связанных данных;
- условия, при которых достаточно локального обновления либо требуется иной способ формирования очищенного результата, без предварительного выбора обязательной полной пересборки.
