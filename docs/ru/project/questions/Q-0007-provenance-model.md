# Q-0007. Provenance model

**Status:** OPEN  
**Area:** Provenance  
**Source:** PREP-00  
**Created:** 2026-09-19

## Вопрос

Какой должна быть нормативная модель provenance в IMXO?

## Контекст

IMXO должен позволять описывать происхождение данных и определять, кем или чем создана конкретная часть структурированных данных. Точная модель проектируется отдельно. Обычное редактирование может создавать несколько производных фрагментов, не превращая provenance в обязанность хранить полную историю либо удалённые при санитизации данные.

## Область вопроса

- структура и гранулярность provenance;
- идентификация источников;
- цепочки преобразований;
- доверенные и недоверенные источники;
- правила наследования provenance;
- взаимодействие с хэшами и подписями;
- происхождение производных фрагментов после копирования, переноса, разделения и объединения;
- различение цепочки преобразований и хранения полной истории изображений;
- несколько фрагментов от одного источника без автоматического подтверждения их текущей семантической классификации;
- ограничения приватности и санитизации: provenance не должен требовать сохранения запрещённых старых данных;
- представление происхождения операции удаления или преобразования без сохранения удалённого значения;
- риск раскрытия удалённого содержания через provenance, производные идентификаторы или хэши;
- допустимая фиксация факта преобразования без создания скрытой истории прежнего содержимого.
