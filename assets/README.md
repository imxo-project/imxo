# IMXO assets

This directory contains visual assets used by the IMXO project.

## Structure

- `brand/kumixo/` — standalone Kumixo mascot artwork and size variants;
- `brand/concepts/` — composite brand boards and icon explorations; these files are references, not final exported logo or icon sets;
- `brand/readme/` — brand artwork prepared for repository overview pages.

Filenames use lowercase kebab-case and describe content or intended use. Size suffixes are used only when two files represent the same artwork at different resolutions.
